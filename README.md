# AI Voice-Controlled Home Assistant

A simple AI-based home assistant that controls smart home appliances using voice commands. The assistant listens to the user's speech, understands the command, performs the requested action, and responds with a natural voice.

## Features

- Voice-controlled home automation
- Google Speech Recognition
- Context-aware command handling
- Neural Text-to-Speech (Edge-TTS)
- Modern GUI using CustomTkinter
- Live appliance status display
- Conversation history

## Technologies Used

- Python
- SpeechRecognition
- Edge-TTS
- CustomTkinter
- Pygame
- Tkinter

## Installation

1. Clone the repository.

```bash
git clone https://github.com/yourusername/AI-Voice-Controlled-Home-Assistant.git
cd AI-Voice-Controlled-Home-Assistant
```

2. Install the required packages.

```bash
pip install SpeechRecognition customtkinter edge-tts pygame pywin32 pyaudio
```

3. Run the application.

```bash
python voice_assistant_ui.py
```
